Coffee Shop Online Ordering System

A full-stack web application that allows customers to browse coffee shop products,
add items to a cart, and place orders online.
The system also includes an admin dashboard for managing products, categories, and customer orders.

*Features
*Customer Features
User registration and login
Browse coffee menu
Add products to cart
Place orders online
View order history
*Admin Features
Admin login
Manage products (add, edit, delete)
Manage categories
View and manage customer orders

*Technologies Used
Frontend: HTML5, CSS3, JavaScript
Backend: PHP
Database: MySQL
Tools: Git, VS Code, XAMPP
